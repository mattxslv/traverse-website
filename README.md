# Traverse 
A travel booking web application built with JavaScript, React, HTML, and CSS.

## Demo
Check out the live version of the app here: [Live Demo](https://silva-traverse.netlify.app/)


## Description
Traverse is a travel booking website designed for adventurous travelers looking to explore exciting destinations. Users can browse available trips, view details about each adventure, and book their next thrilling journey. The app is built using React for dynamic UI updates, with HTML and CSS for structure and styling.

## Features
- Browse a variety of adventure trips and destinations.
- View detailed trip information including location, activities, duration, and cost.
- Booking functionality for travelers to reserve their spots.
- Responsive design for mobile and desktop use.

## Technologies Used
- JavaScript
- React
- HTML
- CSS
- API
